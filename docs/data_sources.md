# Data Sources

## NOAA SWPC

Purpose:
Space weather monitoring.

Data Used:
- Solar Flux
- K Index
- X-Ray Flux
- Radio Blackout Status
- Aurora Forecast

Website:
https://www.swpc.noaa.gov/

Update Rate:
5–60 minutes

## NASA SDO

Purpose:
Solar imagery.

Data Used:
- 171 Å
- 304 Å
- 131 Å

Website:
https://sdo.gsfc.nasa.gov/

## SOHO LASCO

Purpose:
Coronal Mass Ejection observation.

Data Used:
- LASCO C2 imagery

Website:
https://soho.nascom.nasa.gov/

## Local Derived Data

Generated by Sarasvati Signals:

- MUF Estimates
- Propagation Scores
- Noise Floor Estimates
- Greyline Calculations
- Polar Attenuation Metrics
